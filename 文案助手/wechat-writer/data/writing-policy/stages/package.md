# 发布配套文案（待人工审核）

仅依据最终正文生成用户主提示词第九节所需内容：四个有实质差别的备选标题（加已审推荐标题合计五个）、约60—90字摘要、约8—14字封面文案、封面配图提示词、约40—70字分享推荐语。
每项文字不新增公司、数字、时间、供货关系、技术能力或因果判断，不透支正文证据。备选标题同样受“展示/定点/计划量产/量产/交付”和法规状态约束，不能只审核推荐标题。
封面提示词描述主体、构图、光线和留白；概念画面注明示意，不假装真实产品图、工程结构图或数据图。这里只交付提示词；5—8张联网配图继续使用平台独立找配图功能，不声称已经生成或取得授权。
资料不足以支持核心结论时，不输出吸睛配套文案，报告缺口。配套文案经模型自查仍须人工核对，不等同于正文已完成的独立两遍审核。
来源方法：用户完整输出要求；标题边界参考qiaomu，视觉和正文对应参考automotive-content-master。
