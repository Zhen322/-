# 跨平台新媒体助手

面向「汽车与车灯产业」的**跨平台内容生产智能体**。覆盖 **公众号、知乎、小红书、X（中文 + 英文，分别组织）** 四个平台，
打通 **运营规划 → 选题研究 → 资料管理 → 图文制作 → 平台适配 → 审核排期 → 接口发布 → 数据复盘** 全流程。

本地运行、数据落库；接口发布以平台真实返回为准，不接受演示数据或人工复制替代。

---

## 一、这个智能体在哪里（两层结构）

系统不是"一个大模型调用"，而是分两层：

| 层 | 文件 | 职责 |
|---|---|---|
| **智能体大脑（Brain）** | `brain.py` | 用模型的**函数调用（tool-calling）**自主决定"下一步做什么"：调用工具 → 观察真实结果 → 继续决策，直到目标闭环。 |
| **能力（Agent）** | `agent.py` | 提供具体能力：规划、选题、事实卡、图文制作、双审核、自动修复、审定、发布、复盘。 |
| 平台规格 | `platforms.py` | 各平台字数 / 图片 / 版式 / 语言规格与六态状态机。 |
| 模型客户端 | `llm.py` | DeepSeek（OpenAI 兼容）客户端，含普通对话与 `chat_tools` 函数调用。 |
| 联网搜索 | `search.py` | 百度网页 / 图片、搜狗微信、Bing 兜底。 |
| 图片渲染 | `media.py` | Pillow 渲染封面 / 竖版卡片 / 图解 / 图表。 |
| 发布适配 | `publisher.py` | X、公众号真实接口适配器（当前未配置凭据，见"五、发布"）。 |
| 持久化 | `store.py` | SQLite + 本地设置，含 `data/settings.json`、`data/workspace.sqlite3`。 |
| 服务端 | `app.py` | 本地 HTTP 服务（默认 **8766**）、后台任务、排期调度器。 |
| 前端 | `static/` | 单页应用：`index.html`、`app.js`、`styles.css`。 |

**大脑自己不写正文**：所有成品正文都由"能力"内部、带证据的专业模型完成；大脑只负责调度，并在检测到四平台成品全部审定后自动闭环、生成交付报告。

## 二、如何启动

### 环境要求
- Python 3.9+
- 首次使用图片功能需安装 Pillow：

```bash
python -m pip install Pillow
```

### Windows（PowerShell）

```powershell
.\start.ps1
```

### macOS / Linux

```bash
bash start.command
```

### 手动启动（任意平台）

```bash
python app.py --port 8766
```

启动后在浏览器打开：

> **http://127.0.0.1:8766**

- 服务只绑定本机地址，更换端口用 `--port`。
- 关闭服务：在运行窗口按 `Ctrl + C`。
- 修改 `app.py` / `brain.py` 等后端代码后需**重启服务**；修改 `static/` 前端文件后直接刷新页面。

## 三、首次配置（必做）

1. 进入左侧【设置】，填写 **DeepSeek API Key**，点击「测试连接」。
   - 默认模型 `deepseek-chat`，接口地址 `https://api.deepseek.com`。
   - 也可使用任意 OpenAI 兼容服务：改"API 地址"和"模型名"即可。
   - 密钥只保存在本机 `data/settings.json`，不会写入日志。
2. （可选）填写 **Tavily Key** 用于更高质量搜索。
3. 设置品牌名、业务定位，点击「保存」。

## 四、怎么用（推荐流程）

### 方式 A：在【智能体】里对话完成（推荐）
1. 点击左侧【智能体】进入对话页：**左栏是历史对话**，中间是对话区，**底部是输入框 + 发送键**（Enter 发送、Shift+Enter 换行）。
2. 点击「+ 新建对话」，直接用自然语言交代需求，例如：
   > 围绕「现代摩比斯出售车灯业务（OPmobility 并购）」，完成四平台（公众号/知乎/小红书/X 中英）成品：先核查现状，补齐素材、选题、事实卡，逐个产出图文，然后双审核、自动修复、带保留审定，最后给出交付报告。
3. 智能体用函数调用自主推进，回答上方的**「思考过程」卡片**会实时显示它的**思考、每一步工具动作、观察结果**——全部是自然语言，不出现代码或 JSON。
   - 卡片默认折叠，标题显示「思考过程 · 用时 X · N 步操作」，点击可展开/收起；
   - 展开后每个工具动作占一行（图标 + 自然语言描述），点击该行动作可再展开查看**该步的结果详情**；
   - 结束时显示绿色「已完成」，处理中显示「正在处理…」。
4. 历史对话保存在数据库，点击左栏即可回看，可删除；多轮对话保持上下文。

### 方式 B：分页面手动操作
左侧主导航精简为 **4 个功能页 + 设置**，其余环节收纳在各页顶部的子标签中：

| 主页面 | 子标签 | 做什么 |
|---|---|---|
| 【资料库】 | 素材资料 | 粘贴笔记、上传文件（.md/.txt/.docx/.html）、导入网页链接；统一编号、可追溯。 |
| 【资料库】 | 选题研究 | 联网研究并产出选题卡：核心问题、角度、大纲、来源、工作量。 |
| 【资料库】 | 内容日历 | 生成 N 周内容日历（平台 / 语言 / 选题 / 形式 / 目标）。 |
| 【项目与制作】 | 项目与制作 | 建项目 → 整理事实卡 → 一键制作四平台成品。 |
| 【项目与制作】 | 审核与排期 | 查看成品与图片；事实 + 语言双审核、自动修复、审定、排期。 |
| 【发布管理】 | 接口发布 | 查看各平台接口能力板与发布六态；配置凭据、发布、核查。 |
| 【发布管理】 | 数据复盘 | 录入真实发布数据，生成发现、调整建议与评论回复草稿。 |
| 【设置】（置底） | — | 模型、品牌、密钥配置。 |

## 六、接口发布（当前状态，如实说明）

发布六态：**待发布 / 执行中 / 平台处理中 / 已发布 / 失败 / 结果未知**。
"生成完成""素材上传成功""接口已接收"**均不等于已发布**——只有平台返回成功并能核对到内容，才记为「已发布」。

- **X**：已实现 OAuth 1.0a 签名、媒体上传（含分块）、发帖 / 串帖、结果查询的真实代码；配置**写权限**开发者凭据后即可自动发布。
- **公众号**：已实现 access_token、`media/uploadimg`、`draft/add`、`freepublish/submit`、`freepublish/get` 的真实代码；需**已认证**公众号的 AppID / AppSecret。
- **知乎 / 小红书**：官方未对个人提供稳定开放的内容发布接口，系统如实标记「接入受阻」，不伪造成功。
- 凭据在【发布管理】→「配置凭据」填写（`X`：API Key/Secret、Access Token/Secret；`公众号`：AppID/Secret），配置后自动核验能力。

> 按当前任务要求，四个真实接口发布暂不执行，成品只做到"审定"。

## 八、边界与版权

- **不编造事实、数字与来源**；无法核实的信息标注「待核实」或留空。
- 联网配图来自百度图片、已记录来源；正式发布前请确认授权。真实图片不足时，系统会以本地渲染的品牌图解（基于事实卡结论，非编造数据）替代并明确提示缺口。
- 图表仅在有真实数据时绘制；平台规则、接口与额度会变化，发布前以平台最新文档为准。

### 9.1 技术方案与平台接口能力确认表

**技术方案**

- 纯本地运行：Python 标准库 `http.server` 提供服务 + SQLite 存储，无需 Web 框架；仅图片渲染依赖 Pillow。
- 智能体：DeepSeek 函数调用（tool-calling）驱动，支持多轮对话；正文由"能力"内部带证据的模型完成。
- 联网：百度网页/图片、搜狗微信、Bing 兜底；Tavily 为可选增强。
- 依赖：Python 3.9+；Pillow（首次启动脚本会自动安装）；可用的 DeepSeek Key；Tavily Key 可选。
- 数据：默认在 `data/`，可用环境变量 `MEDIA_AGENT_DATA` 改到其他目录。

**平台接口能力确认表**

| 平台 | 接口能力 | 账号条件 | 依赖 | 接入受阻项 |
|---|---|---|---|---|
| 公众号 | 已实现 access_token / 图片上传 / 草稿 / 发布 / 发布结果查询 | **已认证**公众号（订阅号或服务号），具备相应写权限 | AppID、AppSecret；服务器可访问 `api.weixin.qq.com` | 个人订阅号无发布接口；未认证账号接口受限；当前未配置凭据 |
| 知乎 | 无个人开放的内容发布接口 | 仅企业/官方合作渠道，个人无公开 OAuth 写权限 | 需官方商务合作 | 官方未对外开放，标记「接入受阻」 |
| 小红书 | 无个人开放的内容发布接口 | 仅企业号 + 开放平台合作 | 需企业资质与开放平台授权 | 官方未对个人开放，标记「接入受阻」 |
| X | 已实现 OAuth 1.0a 签名 / 媒体上传（含分块）/ 发帖 / 串帖 / 结果查询 | X 开发者账号，App 具备 **写权限**（read/write） | API Key/Secret、Access Token/Secret；可访问 `api.x.com` | 免费套餐发帖额度极低；当前未配置凭据 |

### 9.3 可运行的内容制作、审核、排期、接口发布流程

流程已全部接通并可真实运行（接口发布在配置凭据后可用）：

1. **制作**：对话中让智能体"做四平台成品"，或【项目与制作】一键制作；产出标题、正文、图片、来源、待核实项。
2. **审核**：`audit_content`（或【审核与排期】）做事实 + 语言双审核，逐条列出问题；有问题 `auto_fix_content` 做定点修复。
3. **审定**：修复后残留、且无法在不编造前提下消除的，`mark_manual_required` 记录，再 `approve_content` 带保留审定。
4. **排期**：`schedule`（或【审核与排期】）设定计划发布时间；`app.py` 内置 20 秒轮询的排期调度器，到点自动触发发布。
5. **接口发布**：`execute_publish` 调 `publisher` 真实接口；`verify_publish` 以平台返回核对，六态流转。

对应 API：`POST /api/.../produce`、`/audit`、`/approve`、`/schedule`、`/publish`、`/verify`；或在对话中由智能体自动完成。

### 9.4 各平台真实发布及异常恢复的验收记录（可回查目标账号）

**当前状态（如实说明）**：按任务要求，四个真实接口发布暂不执行；`platform_creds` 为空，故**尚无真实发布验收记录**。系统不伪造记录。

**配置凭据后会自动产生的验收记录（每条 publish 持久化）**

- 平台 / 账号 / 语言 / 版本 / 目标内容 ID
- 发布六态、平台返回的文章/帖子 ID、请求时间
- 异常时的错误类别、错误码、恢复动作、重试次数
- 核查结果（是否能在目标账号回查到该内容）

**回查目标账号结果的方法**

- 系统侧：`GET /api/contents/<id>/verify` → 以平台返回（如公众号 `freepublish/get`、X 结果查询）核对，状态不确定时先核查再决定是否重试，避免重复发布。
- 人工侧：登录对应账号后台，按记录中的帖子/文章 ID 或标题核对；发布结果不确定时不重复发布。

**异常恢复（6 类）**：凭据/授权失败、网络超时、限流（HTTP 429，指数退避）、媒体上传失败、平台审核中/处理中、发布结果未知。每类记录处置与重试，结果可回查。

### 9.5 部署、账号授权、日常操作、费用监控、备份恢复

- **部署**：本地启动即可（见"二、如何启动"）。默认端口 8766，可用 `--port` 或 `MEDIA_AGENT_PORT`；数据目录可用 `MEDIA_AGENT_DATA` 改。服务只绑定本机地址。
- **账号授权**：【设置】填模型 Key；【发布管理】填平台凭据（X 四件套 / 公众号 AppID·Secret），保存后自动核验；凭据只存在本机 `data/settings.json`，不进日志。
- **日常操作**：默认进入【智能体】对话即可；需要逐步核对时用各功能页（顶部子标签切换环节）；发布后在【发布管理 → 数据复盘】录入真实数据。
- **费用监控**：DeepSeek 每次调用返回 token 用量，`llm.py` 累计并在任务结果中展示 `total_tokens`；可据此估算费用，避免无谓的反复重审。
- **备份恢复**：直接备份整个 `data/` 目录（`workspace.sqlite3` + `settings.json` + `media/`）。恢复时把 `data/` 放回再启动即可；更换电脑同理。建议定期复制 `data/` 到安全位置。

### 9.6 尚未实现或受平台权限限制的清单

| 项 | 原因 | 解决条件 | 影响 |
|---|---|---|---|
| 四个真实接口发布 | 任务明确暂不做 | 提供写权限凭据并授权后执行 | 成品只到"审定"，无真实发布记录 |
| 知乎发布 | 官方未对个人开放写接口 | 官方商务合作 / 企业开放平台 | 无法自动发布，需人工发布 |
| 小红书发布 | 官方未对个人开放写接口 | 企业号 + 开放平台授权 | 无法自动发布，需人工发布 |
| X 自动发布 | 未配置开发者凭据；免费套餐额度极低 | 开发者账号写权限 + 凭据 | 配置前不可用 |
| 公众号发布 | 未配置凭据 / 个人号无权限 | 已认证账号 + AppID·Secret | 配置前不可用 |
| 残留事实项（MOU/最终协议/生效/交割年份、净债务、汇率基准日、星宇数据口径、部分工厂数量等） | 源材料截断或仅单一来源，系统不臆造 | 人工核对官方公告 / 补第二来源 | 正文带"待核实/带保留"标注，需人工确认 |
| 联网配图版权 | 百度图片来源版权不明 | 正式发布前确认授权 | 无授权时改用本地品牌图解 |

## 目录结构

```
跨平台新媒体助手/
├─ app.py            # HTTP 服务 + 后台任务 + 排期调度器（默认 8766）

├─ chat.py           # 对话式智能体：多轮 + 自然语言过程
├─ agent.py          # 八大环节能力
├─ platforms.py      # 平台规格 / 六态 / 目标
├─ llm.py            # DeepSeek（OpenAI 兼容）客户端
├─ search.py         # 百度网页/图片、搜狗微信、Bing 兜底
├─ media.py          # Pillow 渲染卡片/封面/图解/图表
├─ publisher.py      # X、公众号真实接口适配器
├─ engine_compat.py  # 网页抓取
├─ store.py          # SQLite 持久化
├─ start.ps1 / start.command        # 启动脚本
├─ e2e_test.py                       # 端到端测试（桩 LLM）
├─ render_samples.py                 # 渲染基础样例
├─ render_all_platforms.py           # 四平台完整风格预览（含 X 中英）
├─ static/            # 前端 SPA
├─ data/              # 数据库、设置、生成图片（含对话持久化）
└─ samples/           # 渲染样例
```
